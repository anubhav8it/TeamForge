# TeamForge Phase 1 Report

This folder contains the **Phase 1 report** for **TeamForge – Skill-Based Hackathon & Project Team Matchmaker**, prepared as part of the PBL course at Graphic Era (Deemed to be University).

## Report Contents

- `main.tex` – Main LaTeX source file
- `TeamForge_Report.pdf` – Final compiled report
- `images/` – Team member photographs used in the report
- `figures/` – Architecture diagram and other figure files

## Overleaf

The report was created and compiled using **Overleaf**.

To edit or compile the report:

1. Upload the complete `Report` folder to an Overleaf project.
2. Open `main.tex` as the main document.
3. Compile using **pdfLaTeX**.
4. Make sure the `images/` and `figures/` folders remain in their original locations.

All files required to compile the report are included in this folder.

## Report Structure

The report follows the prescribed PBL proposal format and includes:

- Project and Team Information
- Motivation
- State of the Art / Current Solution
- Project Goals and Milestones
- Project Approach
- System Architecture
- Project Outcome / Deliverables
- Assumptions
- References
