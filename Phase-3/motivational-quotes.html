How the app chooses (core/Motivation.cpp)

  1. No skills yet → First steps.
  2. At least half the skills self-rated level 4+ → Experience. Entering a skill alone never triggers it.
  3. Every skill at level 1–2 → Keep learning.
  4. One skill → Focus; two or more → Versatility. Learning interests add Keep learning to the pool.
  5. Before Express interest → Collaboration or Teamwork. New host project → Leadership, Build or Innovation. Onboarding step 01 → Growth.

Within one visit the quote stays put while the rule's result stays the same, so typing never reshuffles it. The last six quotes shown are held in a queue and skipped while another is available, so the same quote never comes straight back. Quotes never affect matching, ranking or any score.
